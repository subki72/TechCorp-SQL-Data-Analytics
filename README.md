## Project Overview

This project simulates a comprehensive data management system for **TechCorp**, a fictional technology firm. It demonstrates the full lifecycle of data engineering and business intelligence, ranging from database architecture design to executive-level reporting.

The primary goal is to showcase proficiency in **SQL (Structured Query Language)** for database manipulation and **Python** for data analysis and visualization.

## Project Structure

* `Portfolio_V3_TechCorp_Engineering.ipynb`: The main Jupyter Notebook containing the source code for database creation, data manipulation, and analysis.
* `techcorp_db.sqlite`: The SQLite database file generated by the script, storing tables for Employees, Departments, and Projects.
* `README.md`: Project documentation.

## Key Features

### 1. Database Architecture & Schema Design
* Designed a normalized relational database schema.
* Implemented **DDL (Data Definition Language)** to create tables: `Departments`, `Employees`, and `Projects`.
* Enforced **Referential Integrity** using Foreign Keys to maintain relationships between entities.

### 2. Data Ingestion & Management (CRUD)
* **Create:** Populated the database with realistic dummy data using batch insertion methods.
* **Read:** Executed complex queries using `JOIN` to merge datasets across multiple tables.
* **Update:** Simulated real-world business scenarios by adjusting project budgets dynamically.
* **Delete:** Managed personnel records by removing inactive employee data while verifying data consistency.

### 3. Business Intelligence & Analytics
* **Financial Analysis:** Aggregated data to visualize departmental budget allocations using **Seaborn** and **Matplotlib**.
* **Workforce Metrics:** Calculated headcount distribution across departments.
* **Project Governance:** Analyzed project timelines and durations to estimate delivery schedules.
* **Executive Reporting:** Generated comprehensive reports linking projects to their respective budgets and Senior Managers (based on tenure logic).

## Sample Insights

Based on the analysis performed in the notebook:

* **Budget Distribution:** The **IT Department** manages the largest portion of the company's project budget, reflecting a tech-heavy focus.
* **High-Value Initiatives:** Identified key strategic projects with budgets exceeding $25,000, such as "App Development" and "Website Redesign".
* **Project Timelines:** Strategic projects like "Sales Strategy" show significantly longer durations compared to operational tasks like "Financial Audit".
